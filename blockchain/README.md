# ROCA Blockchain Testbed (Hardhat + Ganache)

This directory contains the smart contract development and testing environment for the **ROCA (Reproducible On-Chain Analytics)** framework.

## Purpose

The contracts and scripts herein generate controlled, verifiable Ethereum transaction streams and event logs to independently validate queries generated by ROCA's Semantic Engine against live Web3 RPC nodes.

## Prerequisites

1. **Ganache** running locally on port `7545` (default RPC URL: `http://127.0.0.1:7545`).
2. Node.js >= 18.

## Installation

```bash
cd blockchain
npm install
```

## Compilation & Testing

```bash
npx hardhat compile
npx hardhat test
```

## Deploying to Ganache

```bash
npm run deploy:ganache
```

## Seeding Benchmark Transactions (15 ETH)

```bash
npm run seed:ganache
```
